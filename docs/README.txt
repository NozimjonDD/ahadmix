AHADMIX LED CITY — пакет нового сайта для IT-отдела
====================================================

Состав сайта (всё, что нужно залить на сервер):
  index.html              — главная страница (вёрстка, стили и JS встроены)
  AHADMIX-KP-2026.pdf     — коммерческое предложение 2026 (кнопка «Получить КП»)
  videos/                 — папка с 70 видеороликами LED-экранов (~576 MB)
                           ❗ Этой папки в архиве нет из-за размера —
                           её нужно скопировать отдельно из той же папки,
                           где вы получили этот архив (рядом лежит videos/).
  README.txt              — этот файл

Что делает сайт:
  • Полностью статичный — никакого бекенда не требуется
  • Все CSS и JavaScript встроены в index.html
  • Подгружает из CDN: Leaflet (карта)
  • Подгружает с https://www.ahadmix.com:
      – фоновое видео hero-блока (bg.mp4)
      – логотипы партнёров (https://ahadmix.com/media/...)
  • Поддержка 3 языков: русский / узбекский (латиница) / английский
  • Адаптивная вёрстка (десктоп / планшет / мобильный)

Развёртывание:
  1. Загрузите index.html, AHADMIX-KP-2026.pdf и папку videos/ в корень домена
     (или поддомена) — все три должны лежать рядом.
  2. Откройте index.html в браузере — сайт готов к работе.
  3. Никакой настройки сервера не требуется (можно положить на любой
     веб-сервер: Apache, Nginx, IIS, GitHub Pages, Netlify, Vercel и т.д.).
